# 系统画像与采集策略实施计划

**目标：** 每次完整扫描或单模块扫描均执行一次只读系统画像，根据所选模块的数据源要求选择采集策略，并在报告中保存实际后端、缺失来源与降级原因。

**边界：** 本计划不新增业务采集模块，不修改输出目录并发行为，不接入 CMDB，不执行外部 Shell 命令。

## 执行流程

```text
执行 scan
  → 读取系统画像
  → 识别发行版、版本、内核、架构、init、cgroup、安全组件
  → 检查所选模块需要的数据源
  → 选择采集策略
  → 执行可用模块
  → 记录实际策略和降级原因
  → 写入报告
```
